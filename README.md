# 카카오톡 메시지 발송 매크로 (macOS)

엑셀·구글시트로 만든 명단대로, 카카오톡 친구들에게 **한 명씩 다른 메시지와 사진을** 자동으로 보내주는 맥용 프로그램입니다.

학원 공지, 안내문 발송처럼 "같은 내용을 여러 명에게, 이름만 바꿔서" 보내야 할 때 씁니다.

> **개발을 몰라도 됩니다.** 설치 파일을 받아서 더블클릭만 하면 되고,
> 막히면 [claude.ai](https://claude.ai)에 물어보면 됩니다. 아래 [막혔을 때](#막혔을-때) 참고.

---

## 이런 걸 할 수 있어요

- 이름별로 다른 메시지 보내기 (한 명씩 개인 채팅으로)
- 메시지에 **사진 여러 장** 같이 보내기
- 카카오톡 친구 목록 전체를 엑셀에 붙여넣을 수 있게 복사하기
- 보내는 중간에 언제든 중지
- 누구에게 성공했고 누가 실패했는지 기록 남기기

## 필요한 것

| 항목 | 내용 |
|---|---|
| 컴퓨터 | **맥(Mac)** 전용, M1 이상 (2020년 후반 이후 모델) |
| 프로그램 | 카카오톡 맥 버전 (PC 버전 로그인 상태) |
| 개발 지식 | 없어도 됩니다 |

윈도우(Windows)에서는 아직 쓸 수 없습니다.

## 설치하기

1. [Releases 페이지](../../releases)에서 맨 위(최신) `KakaoMacro_Installer_v○.○.○.dmg`를 내려받으세요.
2. 받은 파일을 **더블클릭**하면 창이 하나 열립니다.
3. 그 창 안의 **`설치하기`** 를 **더블클릭**하세요.
   - "확인되지 않은 개발자" 경고가 뜨면: 마우스 **오른쪽 클릭 → 열기 → 열기**
4. 설치가 끝나면 설정 창이 자동으로 열립니다. 목록에서 **카카오톡매크로**를 **켜 주세요**.
   - 이미 목록에 있다면, **`ㅡ` 버튼으로 지운 뒤 `+` 버튼으로 다시 추가**해야 합니다.
     (프로그램을 새 버전으로 바꾸면 켜져 있어도 무효가 되는, 맥의 특성입니다)

> ⚠️ **DMG 창 안의 앱을 직접 실행하지 마세요.** "손상되었습니다" 오류가 납니다.
> 반드시 `설치하기`를 거쳐서 응용 프로그램 폴더에 설치된 앱을 쓰세요.

설치가 막히면, DMG 창 안의 **`클로드와 함께 설치하기.txt`** 파일을 열어보세요.
그 내용을 통째로 복사해 [claude.ai](https://claude.ai)에 붙여넣으면 안내해 줍니다.

## 명단(CSV) 만들기

구글 스프레드시트나 엑셀에서 이런 표를 만들고 **CSV로 저장**하면 됩니다.

| 친구명 | 메시지 | 이미지 |
|---|---|---|
| 홍길동 | 안녕하세요! 내일 수업 안내드립니다. | |
| 김철수 | 철수 어머니, 자료 보내드려요. | /Users/내이름/Desktop/안내문.png |
| 이영희 | 사진 3장 함께 보냅니다. | /Users/내이름/Desktop/1.png;/Users/내이름/Desktop/2.png |

**규칙 세 가지만 기억하세요.**

1. **친구명은 카카오톡에 저장된 이름과 글자 하나까지 똑같아야** 합니다.
   (프로그램의 `친구 목록 가져오기` 버튼으로 실제 이름을 복사해 쓰면 안전합니다)
2. **사진이 여러 장이면 세미콜론 `;`으로 구분**합니다. 쉼표(`,`)는 안 됩니다.
3. **사진 경로는 전체 경로**로 씁니다. 파인더에서 파일을 오른쪽 클릭 → `option` 키를 누르면
   "경로 복사"가 나옵니다.

열 이름은 `친구명` 대신 `이름`, `받는사람`, `name` 등을 써도 알아듣습니다.
`메시지`는 `내용`, `문자`, `message` 등도 됩니다. `이미지` 열은 없어도 됩니다.

저장할 때 **CSV(쉼표로 구분된 값)** 형식을 고르세요. 구글 스프레드시트는
`파일 → 다운로드 → 쉼표로 구분된 값(.csv)` 입니다.

## 보내기

1. **카카오톡을 먼저 실행**하고, **친구 탭**을 열어두세요. (채팅 탭 아님)
2. **카카오톡매크로**를 실행합니다.
3. `CSV 파일 선택`을 눌러 만들어 둔 명단을 고릅니다.
4. 미리보기에서 이름·메시지·사진 장수가 맞는지 확인합니다.
   - 사진 칸에 `⚠ N장 없음`이 뜨면 경로가 틀린 것입니다. 명단을 고쳐서 다시 불러오세요.
5. `발송 시작`을 누릅니다.
6. 멈추고 싶으면 `중지`를 누릅니다. (하던 한 명까지만 마치고 멈춥니다)

보내는 동안 **마우스와 키보드를 건드리지 마세요.** 프로그램이 카카오톡 창을
직접 조작하기 때문에, 중간에 다른 창을 클릭하면 엉뚱한 곳에 입력될 수 있습니다.

## 막혔을 때

프로그램 로그 창 오른쪽 위의 **🩺 진단 리포트 복사** 버튼을 누르세요.
지금 상태와 기록이 통째로 복사됩니다. 그걸 [claude.ai](https://claude.ai)에
**그대로 붙여넣기만** 하면 됩니다. 무엇을 물어볼지 고민할 필요 없습니다.
(리포트 안에 "이런 사람이 물어보는 거고, 이렇게 도와주라"는 안내가 이미 들어 있습니다.)

무료 계정으로도 됩니다. 그래도 해결이 안 되면
[Issues](../../issues)에 진단 리포트를 붙여 등록해 주세요.

### 자주 있는 문제

| 증상 | 해결 |
|---|---|
| "손상되었습니다"라며 안 열림 | DMG 안의 앱을 직접 실행한 경우입니다. `설치하기`로 설치한 앱을 쓰세요 |
| 카카오톡 창은 뜨는데 "윈도우를 찾을 수 없음" | 손쉬운 사용 권한이 무효 상태입니다. `ㅡ`로 지우고 `+`로 다시 추가하세요 |
| 친구 목록을 못 가져옴 | 카카오톡에서 **친구 탭**을 열어두세요 |
| 사진이 1장만 감 | 구분자가 쉼표일 수 있습니다. **세미콜론 `;`** 으로 바꾸세요 |
| 특정 사람만 사진이 안 감 | 그 채팅방이 파일 붙여넣기를 받지 않는 경우입니다. 메시지만 발송됩니다 |
| 친구를 못 찾음 | 이름이 정확한지 확인하세요. `친구 목록 가져오기`로 실제 이름을 복사해 쓰면 확실합니다 |

## 프로그램을 고치고 싶다면

이 프로그램은 **클로드(Claude)가 고치는 것을 전제로** 만들어졌습니다.
직접 코드를 읽지 않아도 됩니다.

1. [Claude Code](https://claude.com/claude-code)를 설치합니다.
2. 이 저장소를 내려받습니다.
3. 폴더에서 클로드를 실행하고, 원하는 것을 한국어로 말하면 됩니다.
   - 예: "발송 사이 간격을 2초로 늘려줘"
   - 예: "이미지 구분자로 쉼표도 되게 해줘"

클로드가 읽을 지침은 [`CLAUDE.md`](CLAUDE.md)에 들어 있습니다. 건드리면 안 되는 부분,
왜 그렇게 짰는지, 어떻게 테스트하는지가 다 적혀 있어서 클로드가 알아서 참고합니다.

바꾼 것을 이 저장소에 반영하고 싶으면 Pull Request를 보내주세요.
모든 변경은 저장소 소유자의 승인을 거칩니다.

### 직접 빌드하기

```bash
python3 -m pip install -r requirements.txt
./build.sh          # dist/ 에 설치용 DMG 생성
python3 gui.py      # 설치 없이 바로 실행 (개발·테스트용)
```

## 주의사항 (꼭 읽어주세요)

- **카카오톡 이용약관상 자동화 도구 사용은 계정 제재 대상이 될 수 있습니다.** 이 프로그램의
  사용에 따른 모든 책임은 사용자 본인에게 있습니다.
- **광고성 정보를 대량 발송하는 것은 정보통신망법 위반이 될 수 있습니다.** 수신자의 사전 동의를
  받은 경우에만 사용하세요. (동의를 받았더라도 광고성 메시지에는 `(광고)` 표시 등 법적 요건이 있습니다)
- 한 번에 너무 많이, 너무 빠르게 보내면 계정이 제한될 수 있습니다. 소규모로 시작해 보세요.
- 이 프로그램은 카카오 및 카카오톡과 아무런 관련이 없는 개인 제작 도구입니다.
