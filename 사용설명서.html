카카오톡 매크로 사용 설명서

1. 최초 설치 (처음 한 번만)

설치하기.command 실행

  1. 설치하기.command 파일을 더블클릭
  2. Enter 키 → 손쉬운 사용 설정 화면 열림
  3. 좌물쇠 클릭 → 암호 입력
  4. 목록에서 카카오톡매크로 찾아서 체크
  5. Enter 키 → 앱 실행

💡 다음부터는 카카오톡매크로.app을 바로 실행하면 됩니다.

2. CSV 파일이란?

쉼표로 구분된 데이터 파일이에요. 표를 텍스트로 저장한 거라고 생각하면 됩니다.

3. 지원하는 헤더 (열 이름)

친구명 열 (아무거나 하나 선택) - 친구명, 이름, name, Name, 받는사람, 수신자

메시지 열 (아무거나 하나 선택) - 메시지, 메세지, message, Message, 내용, 문자

4. CSV 만드는 법

Coda.io에서 만들기

  1. 표(Table) 만들기
  2. 첫 번째 열 이름: 친구명
  3. 두 번째 열 이름: 메시지
  4. 데이터 입력
  5. 표 오른쪽 상단 ⋯ 클릭 → Export → CSV

Google Spreadsheet에서 만들기

  1. 새 스프레드시트 만들기
  2. A1셀: 친구명, B1셀: 메시지
  3. 2행부터 데이터 입력
  4. 파일 → 다운로드 → 쉼표로 구분된 값(.csv)

5. CSV 예시

친구명 메시지
홍길동 안녕하세요! 내일 회의 참석 부탁드립니다.
김철수 생일 축하해요!

6. 주의사항

⚠️ 반드시 "친구" 탭으로!

  • 카카오톡을 "친구" 탭이 선택된 상태로 띄워두세요
  • "채팅" 탭이 아닙니다! 반드시 "친구" 탭!
  • 친구 목록이 보이는 화면이어야 합니다

친구명은 정확히!

  • 카카오톡에 저장된 이름과 글자 하나까지 똑같아야 합니다
  • 공백, 띄어쓰기 주의!
  • 예시: "홍길동" ≠ "홍길동 " (뒤에 공백)

빈 칸은 자동 제외

  • 친구명이나 메시지가 비어있으면 자동으로 건너뜁니다
  • 제외된 항목은 팝업으로 알려드려요

7. 프로그램 사용법

메시지 발송

  1. 카카오톡 먼저 실행 (⚠️ "친구" 탭 열어두기!)
  2. 카카오톡매크로.app 실행
  3. CSV 파일 선택 클릭
  4. 미리보기에서 확인
  5. 발송 시작 클릭
  6. 중간에 멈추려면 중지 클릭

친구 목록 가져오기 (Coda 연동용)

카카오톡 친구 목록을 클립보드에 복사합니다.

  1. 카카오톡 "친구" 탭 열기
  2. 친구 목록 가져오기 버튼 클릭
  3. 완료 후 Coda/Excel 등에서 Cmd+V로 붙여넣기
  4. 한 셀에 한 명씩 자동으로 입력됩니다

8. 문제 해결

증상 해결 방법
앱이 손상되었습니다 설치하기.command 다시 실행
카카오톡이 실행 중이 아닙니다 카카오톡 앱 먼저 실행
친구를 못 찾음 이름이 정확한지 확인, "친구" 탭인지 확인
친구 목록을 가져올 수 없습니다 "친구" 탭 열어두고 다시 시도
CSV 읽기 오류 UTF-8 인코딩 확인
권한 오류 시스템 설정 → 손쉬운 사용 → 앱 체크
