■ 카카오톡매크로 설치 안내
  (막히면 이 파일 전체를 복사해서 claude.ai 에 붙여넣으세요 — 무료 계정도 됩니다)

━━━ 사람용: 딱 3단계 ━━━

1. 이 창에 있는 "설치하기.command"를 더블클릭하세요.
   ("확인되지 않은 개발자" 경고가 뜨면: 마우스 오른쪽 클릭 → 열기 → 열기)

2. 설치가 끝나면 자동으로 열리는 '손쉬운 사용' 설정 창에서
   '카카오톡매크로'를 켜세요.
   (이미 목록에 있다면 'ㅡ' 버튼으로 지운 뒤 '+'로 다시 추가해야 확실합니다)

3. 끝! 앱은 '응용 프로그램' 폴더에 있습니다.
   ⚠ 이 창(DMG) 안의 앱을 직접 실행하지 마세요 — "손상" 오류가 납니다.

막혔을 때: claude.ai 를 열고 이 파일 전체를 복사해 붙여넣은 뒤,
지금 상황을 한 줄만 덧붙이세요. 예: "손상되었다고 떠요"

━━━ 여기부터는 클로드에게 주는 정보 ━━━

[클로드에게] 사용자는 개발 지식이 없는 비개발자이며, macOS(Apple Silicon)용
'카카오톡매크로' 앱(카카오톡 자동 메시지 발송 도구, PyInstaller로 빌드된 PyQt6 앱)을
DMG로 설치하는 중입니다. 해결 방법을 한 번에 한 단계씩, 쉬운 말로 안내해 주세요.
터미널 명령은 복사-붙여넣기만 하면 되는 형태로 제시해 주세요.

설치 구조:
- DMG 안의 '설치하기.command'가 앱을 /Applications 에 복사하고,
  격리(quarantine) 속성을 xattr -cr 로 제거한 뒤, 앱과 손쉬운 사용 설정 창을 엽니다.
- 앱은 ad-hoc 서명(Apple 공증 없음)이라, 격리 해제가 안 되면 실행이 막힙니다.
- 앱이 카카오톡을 제어하려면 '손쉬운 사용'(접근성) 권한이 필수입니다.

자주 있는 문제와 해결:
1) "손상되었기 때문에 열 수 없습니다" / "디스크 이미지를 추출해야 합니다"
   → DMG 안의 앱을 직접 실행했거나 격리가 안 풀린 것. 터미널(응용 프로그램→유틸리티)에
     아래 두 줄을 순서대로 붙여넣게 하세요:
       xattr -cr /Applications/카카오톡매크로.app
       open /Applications/카카오톡매크로.app
     /Applications 에 앱이 없다면 먼저 DMG의 앱을 응용 프로그램 폴더로 드래그하게 하세요.
2) 설치하기.command 실행 시 "확인되지 않은 개발자" 경고
   → 파일을 마우스 오른쪽 클릭 → 열기 → 열기. 안 되면
     시스템 설정 → 개인정보 보호 및 보안 맨 아래의 "그래도 열기".
3) "명령어 라인 개발자 도구를 설치하시겠습니까?" 팝업
   → '취소'해도 설치에 지장 없습니다 (구버전 흔적).
4) 앱은 실행되는데 "윈도우를 찾을 수 없습니다" 등 동작을 안 함
   → 손쉬운 사용 권한이 무효 상태. 앱을 업데이트하면 토글이 켜져 보여도 무효가 됩니다.
     시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 '카카오톡매크로'를
     'ㅡ'로 완전히 제거한 뒤 '+'로 다시 추가하고(토글 껐다 켜기로는 안 됨) 앱을 재시작.
5) 인텔(Intel) 맥
   → 이 앱은 Apple Silicon(M1 이상) 전용이라 실행할 수 없습니다.
6) 위 방법으로 해결이 안 되면
   → 앱이 실행되는 상태라면: 앱 로그 패널의 '🩺 진단 리포트 복사' 버튼을 누르고
     그 내용을 이 대화에 붙여넣게 하세요.
   → 앱 실행조차 안 되면: 화면에 뜬 문구를 그대로 받아 적어
     프로그램 제작자에게 전달하라고 안내해 주세요.
